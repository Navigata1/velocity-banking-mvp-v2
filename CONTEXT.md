# InterestShield Domain Language

- **Educational projection:** A conditional numerical estimate under the model's
  stated assumptions. It is not confirmation of a lender's actual obligations.
- **Lender-term input completeness:** All required lender-term fields contain
  valid values. Explicit zero is a value; an absent field is unknown.
- **Term provenance:** The declared source of a supplied value. Document-sourced
  records user-provided provenance, not verification or approval by InterestShield.
- **Model support:** A term's behavior is implemented and enforced by the active
  numerical model. A complete field or source label does not establish support.
- **Forecast basis:** The assumptions and supported inputs under which a result
  was calculated. Distinct scenario families do not acquire each other's terms.
- **Lender-aware projection readiness:** Complete inputs and required context
  are actually supported by the numerical model. It does not mean lender approval.
- **Active scenario copy:** The versioned scenario currently selected for reading
  and editing, distinct from preserved older source documents.
