# Depth-Aware Hero UV Repair

## Verdict

Bounded material-coordinate repair, not a new visual direction or photorealism
approval. Original posters, geometry, stage, camera, lighting, finite eight-second
revolution/one-second rest, controls and financial calculations remain unchanged.
This closes the confirmed collapsed normal-map charts on House reveals, Credit
Card/coin edges and Student Loan ribbon sides/caps. Collection art remains open.

## Reproduction And Repair

The actual distributed Meshopt GLBs failed six new tests before implementation.
Scene traversal found 244 / 2,704 / 1,040 nondegenerate, scene-used, normal-mapped
triangles with collapsed UVs in House / Credit Card / Student Loan respectively.
The repaired artifacts have zero such failures. Unique geometry and scene-use
triangle counts differ deliberately; tests inspect the surfaces actually used.

- House retains Three's extrusion depth charts, divided by the original 3.1
  scale. Front/back XY charts remain unchanged.
- Card uses native edge U and zero-aligned Z at the original face-scale density
  only where XY projection collapsed. Coin front/back charts remain unchanged.
- Student Loan duplicates seam vertices after computing the original normals,
  preserving smoothing and broad-face charts while adding depth-aware sides/caps.
  Export optimization changes vertex ordering/count; no byte-identical accessor
  or unchanged vertex-order claim is made.

Independent decoded before/after comparison confirms exact oriented position and
normal triangle multisets, all previously noncollapsed UVs, bounds, transforms,
materials, samplers, full copyright strings and all 21 embedded images unchanged.
Existing degenerate geometry is unchanged, not claimed repaired. Seven other
GLBs, all ten posters and all nine financial-engine modules remain untouched.

Review found a test-oracle gap: NaN/Infinity charts incorrectly passed. New
actual-model controls reproduced three failures before explicit finite-coordinate
and determinant checks were added. Constant, NaN and both infinities must now be
rejected. Thirteen additional Student Loan helper tests pin original geometry,
winding, normals and broad-face UVs and reject selective chart/preservation faults.
