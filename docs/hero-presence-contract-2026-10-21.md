# Hero Stage Presence Contract

This checkpoint improves the delivered size of all ten real hero models. It is
not a replacement for the original artwork, a new visual direction, final
photoreal approval, or production clearance. The original calm dashboard,
artwork-first opt-in, four vitals, coaching copy and financial engine remain.

## Bounded Change

The previous camera fitted a coarse bounding sphere. That sphere left unnecessary
empty space around the models. The new shared helper measures referenced static
vertices after node/ancestor/instance transforms, retaining each radius/Y pair
about the actual turn origin. It computes perspective side/top/bottom support
over a complete revolution, with the original 1.08 margin and near/far limits.
There is no guessed asset-specific scale or favorable-angle-only fit.

The profile is extracted once when a model loads. The scalar camera fit runs on
load/resize, not animation frames. Skinned, morphing, nonfinite, empty or invalid
referenced geometry fails closed to the existing artwork path. This contract
covers the ten currently shipped static models, not arbitrary animated GLTFs.

The browser and HyperFrames consume the same helper. Camera FOV/direction,
lighting, environment, exposure, all GLBs/posters/manifests and the finite
eight-second smooth revolution plus one-second rest are unchanged. HyperFrames
keeps its 1920x1080 canvas and reserves a 1920x920 art viewport at screen y50..970;
credits and progress remain outside that artwork region.

## Proof That Must Remain

- Twelve pure perspective fixtures and eighteen real Three/decoded-asset cases.
  Independent NodeIO world coordinates, actual instance TRS, nine aspects per
  model, and continuous-yaw worst-plane witnesses test all ten pinned GLBs.
- Six shared presentation controls reject blank, undersized, clipped, malformed,
  unknown-domain and footer-only evidence. Browser/video use the same criteria.
- Three pure pipeline controls execute the real video verifier with IO-only
  adapters and real PNGs. Review exposed clipped-middle/rest false positives;
  both first failed, then passed after enforcing containment at every existing
  0/4/8.5-second sample. Initial-only height minima remain initial-only.
- Initial actual old compiled Car: 28.3% canvas height; inherited old video:
  34.1% art-region height. Both fail the predeclared Car minimum of 38%.
- Original RGB-delta/2% area/edge checks remain. Added starting-silhouette minima:
  Car38%, House57%, Land58%, Card72%, Student50%, Medical58%, Personal56%,
  Recreation71%, Custom70%, Vault58%. These are regression thresholds, not art
  scores. Original motion/cadence/readiness/deadline and asset budgets stay fixed.
- Fresh desktop/375px real-model screenshots, reduced-motion and failure paths;
  all ten new 1080p/9s HyperFrames exports with size/motion/closure/rest checks.
- Independent math/measurement and integration reviews identify exact byte pins.
  Complete local gates, both exact-head GitHub CI events, exact READY preview,
  hosted financial/routes/hash checks and actual browser evidence precede receipt.

The serial sweep initially ran 216 media cases. The three review-driven pipeline
cases are included in a separate final-source full 219-case media run and the
new exact-head CI; initial results are not retroactively relabeled.

The retained local proof lives in
`ops/mission/evidence/hero-presence-2026-10-21/local-preflight.json`. Its evidence
distinguishes preflight from later exact-head verification. A software checker
pass does not resolve the inherited hardware/D3D X4122 diagnostic.

## Still Open

Size is not photorealism. Controlled front/mid/rest material and identity review
against the original artwork remains required. Car paint/interior normal fidelity
from the prior checkpoint is preserved, while Tireside remains unchanged lossy.
Masonry, foliage, fabric, leather, enamel, metal and white-case responses still
need individual art judgment. No blanket full-size/all-angle approval is implied.

Canonical scenario ownership, lender/calendar/reserve behavior, broader fair
comparisons, dedicated backend/recovery, accessibility, physical native/device
verification and release gates remain open. No production promotion, merge,
dependency installation, paid GPU, backend/schema/data/access or domain mutation
belongs to this checkpoint.
