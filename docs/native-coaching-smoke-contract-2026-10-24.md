# Native Coaching Smoke Contract

Current Plan retains the actual shared coaching detail for healthy final payments.
The rendered fixture requires the scheduled-payment pause explanation and rejects
the former generic readiness text. One-month payoff and failure/guardrail checks
remain unchanged at 280, 375 and 1440px across five routes and reloads.

The optional `exportDirectory` fixture argument selects an existing export for
both before/after hashing and served-byte checks. Standalone callers may provide
`MOBILE_COACHING_EXPORT_DIR`; the unchanged default is `apps/mobile/dist-web`.
This permits fresh preserved exports without replacing old test outputs. It does
not build, clear caches, alter financial inputs or waive storage/pixel/deadline
checks. The standalone 180-second deadline is unchanged.
