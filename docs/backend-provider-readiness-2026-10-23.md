candidate. This is not an established app binding; its reference and provider release
details are retained in the private investigation record, not published as an app
configuration. A tracked-file reference search across apps, packages, docs, ops and
supabase found no matching reference. No decrypted hosting environment, API keys,
database rows, SQL, backups or account settings were read. No project was selected,
linked, created, upgraded or modified.

The known Vercel app project's current environment inventory was also read with
`decrypt=false`: one project-level record, `NEXT_PUBLIC_SITE_URL` for production,
zero Supabase keys and zero hidden production records. Values were not decrypted,
printed or copied into evidence. This corroborates missing project-level backend
configuration, not a historical deployed-build or complete inherited-runtime audit.

Before association, corroborate the project reference against the intended environment
and ownership boundary; review its patch/backup state in an approved isolated context.
The current local SQL/RLS CI gate remains functional proof, not managed recovery proof.

Supabase's September25 notice announces PostgreSQL17.11/15.19, security fixes and
upgrade checks for certain extensions/operators. The candidate's provider release-string
mapping and actual affected features were not independently established. Check supported
patch status and follow the provider's pre-upgrade detection/backup procedure, not a
blind in-place upgrade. [Official upgrade notice](https://supabase.com/changelog/postgres-15-19-17-11-breaking-changes).

The October12 notice schedules removal of four older TLS1.2 CBC suites from project HTTP
APIs starting November10 at the earliest. Include supported TLS and physical native-device
compatibility in release QA. [Official TLS notice](https://supabase.com/changelog/cbc-tls-ciphers-deprecated).

The metadata refresh does not close dedicated association, API/JWT isolation, six-table
negative coverage, backup/restore, account recovery, deletion or production release gates.
